# 判断与回滚规则

## 一、三类判断（校对阶段唯一的分支）

先判「是不是错误」，再判「怎么改」。两步混在一起，噪音会淹没信号。

| 类 | 判据 | 动作 | 记录 |
|---|---|---|---|
| 不是错误 | 正常口语、重复、口头禅、专名、引述 | 原样放过 | 不记录 |
| 能推就改 | 音近/形近 + 语义等价 + 上下文支持，且不碰数字人名 | 改 | 记 `inferred`，附依据 |
| 真难 | 人名、金额、方言、多解 | 原样保留 | 不标记、不阻塞 |

**「不是错误」是第一大类**，实测占比可达六成。把它误判成待处理，会凭空制造工作量。

## 二、六条不改

1. 数字、分数、比例、年份、金额
2. 人名、机构名、课程名（拿不准时）
3. 口语重复与语气词（嗯、啊、那个、就是说、对吧）
4. 引述他人的话（哪怕是荒诞说法，那是原话）
5. 同一处有多个同样合理的解
6. 改动后无法被上下文佐证的

## 三、四条红线

1. 不改结构：段数、顺序、时间戳逐段一致
2. 不增信息：不许补例子、结论、背景、解释
3. 不改立场：否定、限定、程度、因果方向不变
4. 不动原始文件

## 四、允许的推断

满足以下全部条件才允许改：

- 音近或形近（拼音、字形相近，不是凭空造词）
- 语义等价（换完意思不变）
- 上下文支持（同篇别处出现过正确写法，或属固定搭配）
- 不涉及数字、金额、人名、机构名

真实案例：

| 原文 | 建议 | 依据 |
|---|---|---|
| 埃批 | IP | 「人设和IP」固定搭配 |
| 黄三 | 高三 | 春季正价课与续班语境 |
| 续力班 | 续班 | 同篇多次出现「续班」 |
| 残渣冷炙 | 残羹冷炙 | 成语固定写法 |
| 放上一老师 | 放上一个老师 | 前文「放上教具、放上桌椅板凳」同句式 |

## 五、硬校验（程序执行，不通过即回滚该段）

| 校验 | 阈值 |
|---|---|
| 数字集合 | 必须完全一致 |
| 单段长度变化 | ≤ 20% |
| 段数、时间戳 | 与原文逐段一致 |

## 六、审核（第二阶段）

**只审被改动过的段落**，未改动的直接通过。

只判三件事：

| 维度 | 定义 |
|---|---|
| 编造 | 出现原文没有的信息、例子、结论、背景 |
| 漏义 | 丢掉关键意思（否定、限定、程度最易丢） |
| 反转 | 意思说反 |

输出只有两档：`pass` / `rollback`，附 20 字内理由。

**禁止**：挑错别字、提新改法、因「可以更顺」判 rollback、拿不准时判 rollback。

审核要宽松。严了会把整理稿退回原文，前面白做。

## 七、回滚规则

- 单段不通过 → 该段用原文
- 整篇回滚率 > 30% → 整篇用原文，标 `low_confidence`
- 回滚由程序执行，**不做二次改写**

## 八、验收指标

| 指标 | 意义 | 参考值 |
|---|---|---|
| 改动密度 | 改动数 ÷ 字数 × 1000 | 3–12 处/千字 |
| 回滚率 | 回滚段 ÷ 审核段 | ≤ 10% |
| 低置信篇数 | 整篇回滚的篇目 | 越少越好 |
| 覆盖率 | 可校篇中实际产出 final 的比例 | ≥ 95% |

**密度低于 3** 说明没认真干（历史上出现过 40% 篇目零改动却报成功）；**高于 12** 说明可能在改写。

## 九、常见失败模式

| 现象 | 根因 | 对策 |
|---|---|---|
| 待办清单暴涨，多数不是错误 | 判断与执行混在一起 | 先分三类，非错误直接放过 |
| 该改的没改（漏字类） | 禁止增删 | 允许从句内增删 ≤2 字 |
| 日志与正文对不上 | 模型分别写正文和日志 | 日志由程序 diff 生成 |
| 大量篇目零改动却报 ok | 整篇处理 + 无密度闸门 | 逐段处理 + 密度校验 |
| 只改开头几段 | 单次上下文过长 | 逐段调用 |
| 改写过度、意思跑偏 | 只给目标不给边界 | 四条红线 + 原文佐证 |
| 审核把合格稿判不合格 | 审核标准过严 | 明确「拿不准判 pass」 |
| 数字被悄悄改动 | 模型顺手「修正」 | 数字集合程序比对 |
