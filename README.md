# corpus-finalizer

A CodeBuddy skill that turns a raw transcript corpus into a readable, publishable version.

It proofreads paragraph by paragraph, hands the audit to a **second agent** (it cannot audit itself), rolls back anything that drifts from the original meaning, re-flows paragraphs for readability, and packs the result into one HTML collection plus machine-readable JSONL.

## Why a second agent

A model reviewing its own edits almost never finds its own mistakes. So the skill stops after proofreading, writes a self-contained audit task, and waits for another agent to return `verdict.json`. Only then does it roll back and finalize.

## Flow

| Stage | Who | Output | Then |
|---|---|---|---|
| G1 ingest | this skill | worklist, normalized text, glossary | **stop** for confirmation |
| G2 proofread | this skill (model A) | `draft.md`, programmatic diff | **stop**, emit audit pack |
| G3 audit | **another agent** | `verdict.json` | read automatically |
| G4 finalize + pack | this skill | `human.md`, `ai.jsonl`, reading pack | deliver |

## Five hard rules

1. Source files are never modified
2. No speech-recognition calls — text only
3. No added information (no invented examples, conclusions, context)
4. No factual changes (numbers, amounts, years, negation, degree, causality)
5. No stance changes

Rules 3–5 constrain content. Structure may be re-flowed in the new documents as long as timestamps stay traceable.

## Output

```
阅读包-<date>/
├─ <creator>-文案合集.html    single-file reader, double-click to open
├─ 全库-段.jsonl              segment level, for retrieval / RAG
├─ 全库-篇.jsonl              document level, for summarisation
├─ 全库.md                    plain text for long-context use
├─ 索引.csv
└─ manifest.json
```

Per document, alongside the untouched `text.md`:

```
draft.md     proofread, structure identical to source
base.md      after rollback
human.md     readable version, paragraphs re-flowed
ai.jsonl     structured segments
```

## Usage

```bash
python scripts/ingest.py --project <corpus dir>
python scripts/proofread.py --project <dir> --key-file <path> --model qwen-plus
python scripts/handoff.py build --project <dir>
# hand 校对/交接/审核任务.md to another agent, it writes verdict.json
python scripts/handoff.py check --project <dir>
python scripts/finalize.py --project <dir> --key-file <path> --model qwen-plus
python scripts/pack.py --project <dir>
```

## Structure

```
├─ SKILL.md
├─ references/
│  ├─ ingest.md          parsing, normalisation boundaries, anomaly matrix
│  └─ judgement.md       three-way triage, red lines, rollback rules, metrics
├─ scripts/
│  ├─ ingest.py          scaffold, parse, glossary, budget
│  ├─ proofread.py       paragraph-level correction with programmatic diff
│  ├─ handoff.py         build audit pack / validate verdict / receipt
│  ├─ finalize.py        rollback, re-flow, four gates, dual output
│  └─ pack.py            HTML collection + JSONL + manifest
└─ assets/standard-card.md
```

## Notes

- Diffs are generated by the program, never written by the model — a self-reported changelog never matches the body.
- The re-flow step never computes timestamps itself; the model returns paragraph ranges and the program derives them, so the timeline stays verifiable.
- Keys are read at runtime and never written to disk or echoed.
